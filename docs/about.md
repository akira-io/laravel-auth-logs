## Contributing
We welcome contributions to the project! Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.

How to contribute:
- Fork the repository on GitHub
- Create a feature branch
- Make your changes and add tests when applicable
- Run the test suite: `composer test`
- Open a pull request with a clear description of your changes

Local testing (package development):
- Clone the repository and run `composer install`
- Use `composer dump-autoload` during development
- Optionally link via a path repository in your app's composer.json
